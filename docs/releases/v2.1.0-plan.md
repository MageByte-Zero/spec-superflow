## 已知边界与发布决策

- recordReview() 底层函数直接接收相对 changeDir 时仍可触发 #137 的路径问题；当前 CLI 已在入口规范化路径。内部调用继续使用绝对目录；若本版扩大到底层相对路径支持，需单独实现和回归，不能把 CLI 验证当作底层函数也已修复。
- finish 当前默认 npm test。非 Node 项目应显式传入 --test-cmd；已验证该覆盖入口。默认命令自动继承属于另一项行为变更，本计划不隐含纳入。
- WorkBuddy 安装器会修改本机插件目录、settings.json 和 installed_plugins.json。已有非 user 作用域和其他插件记录必须保留；登记损坏时停止替换。兼容性已在 5.7.7 验证，不声称覆盖所有客户端版本。
- 妙手只按用户确认的本地导入包范围交付。客户端导入、云端模式、Node/Git 可用性及真实模型任务的后续验收不得记为已通过。

## 中止与恢复

任一必须检查失败时停止发布，记录失败并修复；不得把失败改写成通过。发布准备前可以修正分支并重跑受影响验证；版本或实现改变后需重新绑定候选源证据。

标签尚未推送时保留 PR 和候选物供调整。npm 发布后不覆盖同一版本、不擅自删除标签或 unpublish；若存在发布缺陷，先记录各渠道实际状态，再由维护者决定补丁版本或市场回退。
